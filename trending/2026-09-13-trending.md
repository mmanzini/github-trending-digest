# GitHub Trending – 2026-09-13 (Sunday)

## Editor's Take

Two repos this week genuinely stand out. **anything2explainer** is a Claude Code / Codex skill that converts any topic into a fully narrated motion-graphics explainer video with TTS voiceover, subtitles, and chapter markers — built entirely in code using Remotion — and it explicitly uses a multi-agent workflow with a subagent critic loop. That's a rich piece of content in itself: Claude Code as a video production pipeline is exactly the kind of demo that illustrates agentic coding beyond the CRUD-app examples. A close second is **tokentab**, a tiny Python CLI that ingests Claude Code, Codex, and Gemini CLI session logs and shows your actual spend by model, project, and day — the kind of developer-experience tooling that fills a real gap for anyone running production AI coding workflows and trying to keep costs legible.
