# GitHub Trending – 2026-09-23 (Wednesday)

## Editor's Take
This week is impossible to read without noticing the Jev/Laya wave: nearly every top repo is either the original "System 1" typed-decision engine (**laya**, 20K stars in five days), a direct port of it to a new runtime (MLX, Qwen3.5), or a tool built on top of it. The content angle most worth chasing is **fast-jev-compaction** — it's a Claude Code plugin that replaces the built-in compaction summary by scoring every tool call and result with a Jev decision, dropping stale entries verbatim. At 6.5K stars in under 48 hours, your audience will want a demo of whether it actually improves long-session quality. Also worth covering: **ZCode** (Z.ai's coding agent harness, 6.5K stars) as a fresh competitor in the same space as Claude Code — the open-source coding-agent segment is filling up fast.
