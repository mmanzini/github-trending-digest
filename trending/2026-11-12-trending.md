# GitHub Trending – 2026-11-12 (Thursday)

## Editor's Take
Two repos are genuinely worth your attention today. **DIYgod/pinky** is a pre-alpha desktop app that lets Claude Code, Claude Desktop, Codex, and Cursor control a real iPhone or Android phone via MCP — with human-in-the-loop gates that hold risky actions (payments, password manager access) until you approve. It's a live demonstration of the supervised-agent pattern that the whole community is debating, and it's already 1,800 stars in under a week. On the monthly chart, **storytold/craft-anything** (28K stars in 12 days) uses Claude Code as its primary coding agent to reverse-engineer any app and rebuild it in a stack you choose; its ~320 tools are exposed both as CLI commands and as MCP tools, making it a compelling case study for how agent-native dev tooling is being designed right now.
