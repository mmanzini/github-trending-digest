# GitHub Trending – 2026-11-04 (Wednesday)

## Editor's Take
Two repositories stand out today. **deepseek-ai/dsh-superagent-prototype** is a rare public prototype of a truly proactive coding agent: it watches a GitHub repo for requests, opens its own work sessions, and replies by filing pull requests — all without being explicitly invoked. This is the agentic loop moving from reactive to autonomous, and it deserves a close read for anyone covering AI agents. **storytold/craft-anything** is a pure-Rust tool that reverse-engineers an existing app or website and rebuilds it from scratch using a coding agent, exposing ~320 tools as both CLI commands and MCP endpoints — Claude Code is a first-class supported backend. Together they represent the week's clearest signal that the gap between "AI-assisted coding" and "AI that writes its own code unprompted" is closing fast.
