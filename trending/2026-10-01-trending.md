# GitHub Trending – 2026-10-01 (Thursday)

## Editor's Take
Two repos stand out this week. **Louis-CFM/coucou** is a native macOS/Windows companion app that watches your Claude Code sessions from the Dynamic Island or menu bar — a tiny but telling sign of how Claude Code has become infrastructure developers build around, not just a tool they use. It's direct Claude Code content bait with an active dev community already forming. **feder-cr/dots** is the open-source answer to OpenAI's browser-agent product, shipping a stealth-browser AI agent (Playwright + MCP + multi-provider) that claims to be undetectable; the timing against OpenAI's own Dots launch makes it a natural "open-source vs big lab" narrative. The broader "jev ecosystem" theme (laya, jev-ultrafast, jevgrep, kev, jeff) is also worth watching — a fast-forming cluster of lightweight System 1 decision models for use inside agents, all independently created this month.
