# GitHub Trending – 2026-11-25 (Wednesday)

## Editor's Take
Two repos stand out this week for AI/agent content creators. **EL4CTEO/fast-anything** is a Claude Code plugin (and MCP server) that profiles a Python, Node, or Ruby app, then uses Claude or Codex to port only the slowest functions to Rust — with recorded real-call replay to verify correctness before enabling anything. It's a compact demo of Claude Code acting as an orchestration engine in a real developer workflow, not just a one-shot code generator, and it's worth covering both for the technical angle and as a template for how agent-skills can be packaged. The 30-day chart is dominated by **storytold/craft-anything** (42k stars), which points a coding agent at any website, app, or game, reverse-engineers it with live inspection, and builds a working clone — a striking example of agentic engineering at scale that will resonate with audiences watching the "AI builds software" narrative.
