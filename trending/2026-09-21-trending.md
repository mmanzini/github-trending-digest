# GitHub Trending – 2026-09-21 (Monday)

## Editor's Take
This week's trending data is dominated by a single emerging paradigm: **Jev / typed decision models** — tiny, sub-20ms ML models designed to make typed binary decisions (semantic if-else) rather than generate text, now being wired into agents as ultra-cheap control-flow primitives. `browser-use/jev-ultrafast` hitting 15k stars in under five days signals this is crossing from research curiosity into practitioner tooling fast. More directly actionable for Claude Code users: `tamaratran/fast-jev-compaction` is a Claude Code plugin that replaces the built-in compaction summarizer with Jev-scored context pruning — every tool call and result is scored in one fast request, stale ones are dropped, and the result is a dramatically leaner context without the information loss of plain summarization. If you cover Claude Code tooling, both of these repos are worth a dedicated video this week.
