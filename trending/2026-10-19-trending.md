# GitHub Trending – 2026-10-19 (Monday)

## Editor's Take
Two repos this week are worth your full attention. **git-ai** (`feder-cr/git-ai`) rethinks version control primitives specifically for AI agents — not just agents using git, but git designed around how agents think and operate. With 2,400+ stars in four days it has real momentum, and for anyone covering the agentic coding stack this is the infrastructure story of the week. **earshot** (`Leonxlnx/earshot`) is the more novel one: it gives coding agents like Claude Code the ability to hear and process audio via MCP, opening a genuinely new sensing modality for agents. It's CPU-only, open source, and already tagged `claude-code` — perfect content for an audience watching the agent capabilities frontier.
