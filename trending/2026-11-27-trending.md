# GitHub Trending – 2026-11-27 (Friday)

## Editor's Take

This week is dominated by the GTA VI PC port moment — a cultural event more than an engineering one, with half the top 10 being VIctory forks and spin-offs. The one repo that genuinely deserves your attention is **EL4CTEO/fast-anything**: a Claude Code plugin and MCP server that profiles your Python/Node/Ruby app and uses a coding agent to port *only the hot 5%* to Rust, with recorded-call verification before it swaps anything in. It's a concrete, practical example of AI agents doing performance work that would otherwise take days of manual profiling and FFI wiring — strong content angle for the "agents doing real engineering" narrative. On the monthly side, **deepseek-ai/dsh-superagent-prototype** (DeepSeek's autonomous agent research) and **heydamir/unslop** (a Claude skill for un-AI-ing vibecoded UIs) round out a genuinely interesting week for the AI/agent space.
