# GitHub Trending – 2026-09-28 (Sunday)

## Editor's Take
This week has a clear theme: the Claude Code / Codex agent ecosystem is generating its own gravity. **yetone/magpie** (menu-bar model switcher: run Codex on DeepSeek, Claude Code on Kimi) and **dzhng/jevgrep** (semantic code search CLI built explicitly for coding agents) both shot up in a single week — together they paint a picture of a tooling layer forming on top of AI coding assistants. Also worth a serious look: the 30-day chart is dominated by **NandhaKishorM/laya** (27k stars), a non-autoregressive decision engine that runs agent routing and yes/no decisions in a single forward pass at claimed 9× the speed of Claude — if that benchmark holds, it's a significant primitive for anyone building multi-agent pipelines.
