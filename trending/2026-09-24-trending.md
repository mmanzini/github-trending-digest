# GitHub Trending – 2026-09-24 (Thursday)

## Editor's Take
Two stories dominate this week and both are worth content. First, **laya** (NandhaKishorM/laya) is having a breakout moment: a non-autoregressive System 1 decision engine that hit nearly 23K stars in under a week, and it's already spawning runtime ports (laya-mlx, laya-coreml) — the kind of ecosystem velocity that signals a genuine paradigm shift, not a hype spike. The angle for your audience is that laya skips text generation entirely and instead makes typed yes/no, score, and choice decisions in a single forward pass, which has real implications for how LLM pipelines handle routing and classification cheaply. Second, **ZCode** from Z.ai (the Zed editor team) is the most direct Claude Code / Cursor challenger to emerge in months: a TypeScript coding agent harness with 6,700+ stars in 4 days, positioning itself as extensible-first.
