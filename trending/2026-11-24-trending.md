# GitHub Trending – 2026-11-24 (Tuesday)

## Editor's Take
Two repos demand attention this week. **EL4CTEO/fast-anything** is the standout story for AI/agent content: it's a tool and workflow explicitly built around using coding agents (Claude Code, Codex) to identify and surgically rewrite just the slow 5% of Python/Node/Ruby code into Rust — with cross-language FFI wiring handled automatically. It hit 3,100+ stars in under 3 days, which signals real resonance with developers tired of "rewrite it in Rust" maximalism. The pitch — profile first, let the agent port the hot path, verify correctness — is a concrete, teachable workflow your audience can run today. Second pick is **deepseek-ai/dsh-superagent-prototype**, a 24k-star TypeScript prototype from DeepSeek framing itself as a step toward fully autonomous agents; the sparse README and rapid star velocity make it a conversation-starter about where autonomous agent systems are heading.
