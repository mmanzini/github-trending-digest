# GitHub Trending – 2026-11-26 (Thursday)

## Editor's Take

This week's trending list was almost entirely consumed by a single cultural moment: the GTA VI PC port wave, with 7 of the top 10 weekly repos all circling the same goal (running the Xbox Series title natively on PC). The one genuine AI/DEV standout is **EL4CTEO/fast-anything** — a workflow tool that profiles hot Python/Node/Ruby paths and ports them to Rust via your coding agent, complete with explicit Claude Code and MCP integration. It's a compelling pattern for anyone building agent-assisted performance workflows. Looking at the monthly window, **deepseek-ai/dsh-superagent-prototype** is worth your attention: a TypeScript prototype from DeepSeek pushing toward more autonomous multi-step agent systems, which speaks directly to where AI agent architectures are heading.
