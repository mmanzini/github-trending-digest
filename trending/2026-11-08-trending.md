# GitHub Trending – 2026-11-08 (Sunday)

## Editor's Take
Two repos demand attention today. `storytold/craft-anything` jumped another 2,500 stars overnight (now 20.5k in just 8 days) and deserves a proper look: it's a Rust reverse-engineering engine where Claude Code is the coding agent, an MCP server exposes 320+ analysis tools to any AI client, and the pitch is "point it at any app and have AI rebuild it in your language of choice." That's one of the most ambitious AI-agent workflows to appear on GitHub this year and a natural breakdown video. Meanwhile, `Gathin23/cleanyourtv` is now closing in on 54k stars — not AI tooling itself, but its topics tell the creator story: `claude-code`, `vibe-coding`. A solo dev used Claude Code to build one of the most viral repos of the month; the meta-angle of "what can a single person ship with AI-assisted dev" is exactly this channel's lane.
