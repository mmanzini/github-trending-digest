# GitHub Trending – 2026-11-05 (Thursday)

## Editor's Take
Two repos this week are worth your full attention. **deepseek-ai/dsh-superagent-prototype** hit 18.5k stars in just five days — DeepSeek is publishing working code toward "a more autonomous agent system," and the architecture decisions here are exactly what the agent-building community is debating right now. **KKKHhazix/agent-autoloop** is a quieter find but arguably more practical: it's a self-driving CLI agent that runs tasks in the background and only pings you when it hits a decision it can't make alone — a genuinely novel UX pattern that Claude Code users will find immediately recognizable. Beyond those two, it's striking how many of this week's top repos are Claude Code skills (pixelfx, teardown, stack-diagram, animated-shorts), signaling a fast-growing third-party skills ecosystem worth tracking as a broader trend.
