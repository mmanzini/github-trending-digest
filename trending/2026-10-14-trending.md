# GitHub Trending – 2026-10-14 (Wednesday)

## Editor's Take
Two repos stand out this week for AI/agent content. **wheresryan22/anatomy** introduces a structured agent skill for generating interactive isometric machine illustrations in SVG—a compelling example of how specialized visual-output skills are expanding what agents can create, and perfect material for showcasing Claude Code's skill ecosystem in action. **liseami/CCBaga** is more meta: a native desktop app (Rust + Tauri) built specifically to manage Claude Code and Claude Desktop identities, with an installable Agent Skill for VPS/proxy setup—tooling that's laser-focused on the Claude developer experience and directly relevant for content about the growing ecosystem around Claude Code. From the monthly list, **browser-use/jev-ultrafast** is also worth watching—the browser-use team billing their latest as the "fastest and cheapest web agent" is a direct shot at two of the biggest pain points in production agentic deployments.
