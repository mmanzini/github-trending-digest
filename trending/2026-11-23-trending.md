# GitHub Trending – 2026-11-23 (Monday)

## Editor's Take
Two repos this week are worth your full attention. **EL4CTEO/fast-anything** is a Claude Code plugin and MCP server that profiles Python, Node, or Ruby apps and uses a coding agent to port hot functions to Rust — it ships with a Claude Code marketplace listing, a skill file, and eight MCP tools, making it a compelling "agents doing real engineering work" story with a tight feedback loop. On the 30-day chart, **storytold/craft-anything** (41k stars) is the more explosive find: it's a desktop app + CLI + MCP server that reverse-engineers any website, app, or game and then delegates to a coding agent (Claude Code natively supported) to build your own version — 320 tools exposed as MCP endpoints, Ghidra integration, and a comparison loop that refines the output automatically. Both repos are directly content-worthy for an audience that cares about where AI agents are actually delivering practical value.
