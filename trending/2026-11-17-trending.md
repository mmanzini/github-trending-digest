# GitHub Trending – 2026-11-17 (Tuesday)

## Editor's Take
Two projects stand out this week. **`storytold/craft-anything`** is the month's most explosive repo (34k stars in ~3 weeks): it's an open-source Rust agent that reverse-engineers any website, desktop app, or game by running real inspection tools, then has a coding agent build a clean-room replica and iterates until the result matches. The architecture is explicitly agent-first—320 tools, each one both a CLI command and an MCP tool—making this a live showcase of how to design agent tooling at scale. For content about AI agents and MCP adoption, there is real material here. **`deepseek-ai/dsh-superagent-prototype`** (23k stars) is DeepSeek's own public research toward a more autonomous agent system; it is sparse on code but heavy on signal about where one of the most-watched AI labs is pushing next, which makes it a good frame for a "what does autonomy actually mean in 2026" piece.
