# GitHub Trending – 2026-11-19 (Thursday)

## Editor's Take
Two repos this week are worth a close look. **erkamyaman/rust-anything** is a MCP-registered tool that lets Claude Code, Codex, and Cursor incrementally rewrite entire codebases in Rust by recording the original's behavior and verifying the port at every step—the agent integration story here is a great explainer hook for how MCP enables real-world coding-agent workflows. **sybil-solutions/inference-optimisation-skill** is a Claude agent skill that hill-climbs local LLM serving speed (decode, speculative decoding, prefill, KV cache, TTFT) and is explicitly designed for Claude Code—niche but directly on-brand for LLM tooling content. Worth pairing them in a single piece on "agents that improve your AI stack."
