# GitHub Trending – 2026-09-18 (Friday)

## Editor's Take
Two repos stand out this week. **`tamaratran/fast-jev-compaction`** (3,142 stars in under 48 hours) is a Claude Code plugin that replaces Claude's built-in context compaction with a Jev-based scoring pass: every tool call and result gets scored in a single fast request, stale entries are dropped rather than summarized away. This is exactly the kind of Claude Code extension that exposes the normally invisible compaction step and makes it controllable — rich material for content on AI coding workflows. **`agentverse-os/AgentVerse-OS`** is a self-hosted developer operating system purpose-built for running AI agents (VS Code, Claude Code, and Codex each get isolated browser workspaces), built in Rust with a Svelte UI and locked behind Tailscale-only access — a compelling vision of the personal "agent infrastructure" layer the community is starting to want. Worth watching separately: three of this week's top repos (`jev-ultrafast`, `SemIf`, `jevlike`) all orbit a new runtime called Jev; it may be the next significant AI inference primitive and deserves its own dedicated look.
