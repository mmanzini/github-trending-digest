# GitHub Trending – 2026-10-17 (Saturday)

## Editor's Take
Two repos stand out this week for the AI/agent creator niche. **`feder-cr/git-ai`** is a version control system built from the ground up for AI coding agents—it rethinks branching, commits, and diffs for how agents actually work rather than bolting AI onto legacy git. This is a direct "what does agentic software infrastructure look like?" story for the Claude Code audience. **`onehumanbeing/esp32-iphone-agent`** takes computer-use in a genuinely novel direction: an AI model controlling a real iPhone through an ESP32 microcontroller using AirPlay video and USB HID input, no jailbreak required. The hardware-as-agent-interface angle opens up content territory that pure software computer-use can't touch.
