# GitHub Trending – 2026-10-16 (Friday)

## Editor's Take
Two repos stand out this week. **esp32-iphone-agent** (onehumanbeing) is a genuine attention-grabber: it lets an LLM agent see an iPhone via AirPlay and control it via USB HID using a $7 ESP32 — no Mac, no developer account, no jailbreak. This is a highly shareable "computer use on a budget" story that lands perfectly for an AI-agents-focused audience. **deeplethe/solid-glass** is the quieter find worth bookmarking: a TypeScript design system built specifically for AI application UIs (chat interfaces, agent dashboards) on top of shadcn, with topics explicitly listing `ai-agents`, `chat-ui`, and `llm` — the kind of building block that developers building AI products are actively hunting for.
